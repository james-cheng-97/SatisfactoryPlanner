# SatisfactoryPlanner

WPF (.NET 10) Satisfactory production planner with a factory layout planner that exports in-game blueprints.

**Before working on the layout planner or blueprint export, read [docs/LAYOUT_DESIGN.md](docs/LAYOUT_DESIGN.md)** —
the design flow, hard rules learned in game, test procedure and open items. Keep it up to date when the flow changes.
